- Added a recursive chmod/chown guard to the kernel bash tool: `chmod`/`chown` invocations carrying a recursive flag (`-R`, `--recursive`, bundled short options, flags in any position) are refused before execution when an operand resolves outside the current workspace (HOME itself, `/`, parent directories, other trees, symlink escapes), names a protected dot path (`.git`, `.env`-class dotfiles and dot-directories), or cannot be checked statically (globs, substitutions, unknown variables); quoted command words and flags scan like their unquoted forms, and `eval`, `sh -c`, `xargs`, and unreplayable `cd` wrappers are refused outright. Explicit bypasses: `bash(command, allow_destructive_chmod=True)` or `PI_BASH_ALLOW_DESTRUCTIVE_CHMOD=1`, where the env bypass is frozen at kernel start so mid-session `os.environ` writes cannot neuter the guard (they are ignored and warned about loudly).
