- Added an opt-in daemon TCP listener for tailnet mesh connections: `--daemon-port <n>` (or `PRIME_AGENT_DAEMON_PORT` / settings `daemonPort`) listens on `0.0.0.0:<port>` alongside the unix socket, serving the same protocol with per-machine token auth. A mesh connection receives the protocol banner in `daemon_hello` and nothing else until its first authenticated line: the supervisor ownership token, pids, process start id, and local paths stay on local connections. No behavior change when unset.
